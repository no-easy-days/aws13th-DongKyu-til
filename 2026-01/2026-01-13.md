### 1. 파이썬 타입 힌트 (Type Hints)

- 변수나 함수에 데이터의 종류(Type)를 단서(Hint)로 남기는 것.
- **특징:**
    - 파이썬 실행 시 강제되지 않음 (틀려도 에러 안 남).
    - 하지만 **FastAPI는 이를 강력하게 활용**함.
- **FastAPI에서의 3가지 역할:**
    1. **데이터 검증:** `int` 자리에 문자가 오면 에러 발생.
    2. **타입 변환:** URL의 문자열 `"42"`를 숫자 `42`로 자동 변환.
    3. **문서 자동화:** Swagger UI에 타입 정보를 자동으로 기재.
- 문법
    - 변수: `name: str = "Jeff"`
    - 함수: `def add(a: int) -> int:`
    - 옵션: `str | None` (문자열 혹은 없음)

### 2. 가상 환경 (Virtual Environment)

- **필요성:** 프로젝트 A는 `Django 3.0`, 프로젝트 B는 `Django 4.0`을 써야 할 때, 전역(Global)에 설치하면 충돌 발생. 이를 방지하기 위해 **격리된 공간**을 만듦.
- **동작:**
    - 가상 환경을 활성화(`activate`)하면, **`PATH` 환경 변수의 맨 앞**에 가상 환경의 경로가 추가됨.
    - 이후 `python` 명령어를 치면 전역 파이썬이 아닌 가상 환경 속 파이썬이 실행됨.
- **핵심 명령어:**
    - 생성: `python -m venv .venv`
    - 활성화: `source .venv/bin/activate` (Mac/Linux) / `.venv\Scripts\activate` (Win)
    - 비활성화: `deactivate`

### 3. 환경 변수 (Environment Variable)

- **개념:** 운영체제(OS) 수준에서 관리되는 변수. 코드 내부가 아니라 외부(터미널, 시스템)에 저장됨.
- **용도:**
    - **보안:** 비밀번호, API Key 등 Git에 올리면 안 되는 민감한 정보 숨기기.
    - **설정 분리:** 개발용 DB, 운영용 DB 주소를 다르게 설정할 때 유용.
- **사용법:**
    - 설정(터미널): `export MY_NAME="철수"`
    - 사용(Python): `os.getenv("MY_NAME", "기본값")` (무조건 문자열 `str`로 읽힘)

### 4. FastAPI 기초

> "빠르고, 쉽고, 문서까지 다 해주는 프레임워크"
> 
- **특징:** 빠른 속도(Node.js급), 적은 코드량, **자동 문서화(Swagger)**.
- **구조:**
    
    ```python
    app = FastAPI()  # 1. 앱 생성
    
    @app.get("/")    # 2. 경로 및 메소드 등록 (데코레이터)
    def root():      # 3. 함수 실행
        return {"msg": "Hello"} # 4. JSON 응답
    ```
    
- **데코레이터(`@`):** "이 URL로 요청이 오면 밑에 있는 함수를 실행하라고 연결해주는 역할.
