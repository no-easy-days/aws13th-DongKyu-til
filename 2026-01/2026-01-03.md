## 📝 배운 내용 (Today I Learned)

### 1. 모듈 분리

- 처음에는 main.py에 모든 코드를 작성했으나, 유지 보수성을 위해 파일을 분리

문제: utils.py에서 파일을 읽어와도, main.py는 그 변수를 자동으로 알 수 없다.
해결: utils.py는 함수를 통해 데이터를 return 해줘야 하고, main.py는 import 해서 변수에 담았음.




### 2. 클래스(Class) vs 인스턴스(Instance)

- 대출 기능을 구현할 때 AttributeError와 논리적 오류를 겪음.

Book.title: 클래스 변수 접근 (설계도 자체를 가리킴, 에러 발생 가능성 높음)
book.title: 반복문 등에서 생성된 실제 객체(인스턴스)의 속성 접근


### 3. 변수(Variable) 이름의 혼동

- 네이밍 규칙: 복수형과 단수형을 상황에 맞게 쓰기
- 불필요한 변수 제거: 코드에 남아있는 더미 변수 정리하기

- => 변수명을 대충 짜거나, 알맞지 않게 짜면 코드를 작성할 때 혼동됨.
