### Fast API 간단한 서버 만들기

- GET과 POST 방식을 사용한 간단한 Fast API 서버
- 메모장 같은 서버를 만듦


```
from fastapi import FastAPI
from pydantic import BaseModel


app = FastAPI()
memos = []


class Memo(BaseModel):
    text = str

@app.post("/memos")
def add_memo(memo:Memo):

    text = memos.append([])
    return("저장되었습니다")


@app.get("/memos")

def get_memos():

    return memos

```



### Fast API 서버에 관리 기능 추가하기

- PUT과 DELETE 방식을 사용하여 수정/삭제 기능 추가
- 인덱스를 활용하여 수정/삭제 진행
```
from fastapi import FastAPI
from pydantic import BaseModel


app = FastAPI()
memos = []


class Memo(BaseModel):
    text: str

@app.post("/memos")
def add_memo(memo:Memo):
    text = memos.append(memo.text)
    return("저장되었습니다")



@app.get("/memos")
def get_memos():
    return memos


@app.delete("/memos/{memo_id}")
def delete_memo(memos_id: int):
    memo = memos.pop(memos_id)
    return ("삭제되었습니다.")


@app.put("/memos/{memo_id}")
def update_memo(memo_id: int, memo: Memo):
    memos[memo_id] = memo
    return ("수정되었습니다.")
```

### Fast API 서버에 sqlite를 활용하여 DB 연동시키기기

```
from fastapi import FastAPI
from pydantic import BaseModel
import sqlite3



app = FastAPI()

class Memo(BaseModel):
    title: str
    content: str


def init_db(__init__): # 이 부분 다시보기
    con = sqlite3.connect("memos.db")
    cur = con.cursor()
    cur.execute("CREATE TABLE NOT EXISTS memos (title TEXT, content TEXT)")

    con.commit()
    con.close()



@app.post("/memos")
def add_memo(memo: Memo):
    con = sqlite3.connect("memos.db")
    cur = con.cursor()
    cur.execute("INSERT INTO memos (title, content) VALUES (?, ?)", (memo.title, memo.content)) #이 부분 다시보기

    con.commit()
    con.close()

    return ("저장되었습니다.")




@app.get("/memos")
def get_memos():
    con = sqlite3.connect("memos.db")
    cur = con.cursor()
    cur.execute("SELECT rowid, * FROM memos")

    rows = cur.fetchall()
    # 이 부분 다시보기

    return rows



@app.put("/memos/{memo_id}")
def update_memo(memo_id: int, memo: Memo):
    con = sqlite3.connect("memos.db")
    cur = con.cursor()
    cur.execute("UPDATE memos SET title=?, content=? WHERE rowid=?", (memo.title, memo.content, memo_id))

    con.commit()
    con.close()

    return ("수정되었습니다.")


@app.delete("/memos/{memo_id}") # 이 부분 다시보기

def delete_memo(memo_id: int):
    con = sqlite3.connect("memos.db")
    cur = con.cursor()
    cur.execute("DELETE FROM memos WHERE rowid=?, (memo_id)")

    con.commit()
    con.close()

    return ("삭제되었습니다.")



```

>
- **과제/문제**:
- # **[Python]Pydantic 타입 힌트 오류**

**[상황]**
FastAPI에서 `BaseModel`을 상속받아 데이터 양식(Class)을 만드는 과정에서 서버 실행 시 에러 발생

**[에러 메시지]**`pydantic.errors.PydanticUserError: A non-annotated attribute was detected: text = <class 'str'>. All model fields require a type annotation`

**[발생이유]**
Pydantic 모델에서는 변수의 타입을 정할 때 **콜론(`:`)**을 사용해야 하는데, 일반 변수 선언처럼 **등호(`=`)**를 사용하여 값을 할당했기 때문임.

- `text = str`은 "text 변수에 str이라는 클래스 자체를 값으로 넣어라"라는 뜻이 되어 규칙 위반임.

**[해결방법]**
등호(`=`)를 콜론(`:`)으로 변경하여 타입 힌트(Annotation) 형식으로 수정

```python
class Memo(BaseModel):
    text: str  # 명찰을 달아주는 방식으로 변경
```

# **[Python]서버 무한 대기(Blocking) 오류**

**[상황]**
서버 코드를 실행한 후 웹 브라우저에서 접속했을 때, 페이지가 넘어가지 않고 무한 로딩되는 현상

**[에러 메시지]**
(에러 메시지는 뜨지 않으나) 터미널 콘솔이 멈춰 있고 브라우저 응답 없음(Timeout)

**[발생이유]**
서버 함수 내부에 사용자의 키보드 입력을 기다리는 **`input()`** 함수가 포함되어 있기 때문임.

- 웹 서버는 요청이 들어오면 즉시 응답해야 하는데, `input()`이 실행되면 서버 컴퓨터의 터미널에서 사람이 타자를 칠 때까지 모든 동작이 멈춤(Blocking).

**[해결방법]**`input()` 함수를 제거하고, 함수의 **매개변수(Parameter)**를 통해 데이터를 전달받도록 수정

```python
@app.get("/hello")
def say_hello(name: str):  # URL 파라미터(?name=...)로 입력받음
    return {"msg": name}
```

## 💭 오늘의 회고 (Retrospective)

- **Keep (좋았던 점)**: 실습을 많이 진행함.
- **Problem (아쉬웠던 점)**: 코드 작성 간 아직 파이썬에 익숙하지 않은 부분이 있었다. ex) 타입 힌트(Type Hints)

-왜 쓰나요? (이유)
1. "자동 검문 검색" (가장 중요!)
FastAPI는 이 타입 힌트를 보고 데이터를 자동으로 검사합니다.

안 썼을 때: def add(a, b):

누가 a="안녕", b="하세요"를 넣으면, 서버는 아무 생각 없이 둘을 더해서 "안녕하세요"를 만듭니다. (숫자 계산기인데 글자가 더해지는 사고 발생)

썼을 때: def add(a: int, b: int):

FastAPI가 "잠깐! a는 정수(int)여야 하는데 글자가 왔네? 에러!"처리

개발자가 일일이 if type(a) != int: 같은 검사 코드를 짤 필요가 없어집니다.

2. "자동 완성 (IntelliSense)"
편집기(VS Code 등)가 똑똑해집니다.

상황: memo. 점을 찍었을 때

안 썼을 때: memo가 뭔지 모르니 아무것도 추천 안 해줍니다.

썼을 때: "아, 이건 Memo 클래스죠? 그럼 title이랑 content가 있겠네요!" 하면서 목록을 띄워줍니다. 오타를 획기적으로 줄여줍니다.

3. 남이 짠 코드를 볼 때(혹은 한 달 뒤의 내가 볼 때) 아주 편합니다.


- def process(data): -> "이 data에 뭘 넣어야 하지? 리스트? 딕셔너리? 문자열?" (코드를 다 뜯어봐야 암)

- def process(data: str): -> "아, 문자열 넣으면 되는구나."

- **Try (시도할 점)**: 이론으로 이해하는 것도 중요하지만, 실습을 진행하며 직접 손으로 익히고 한 줄씩 분석해가는 것이 실력 향상에 도움이 많이 되는 것 같다.
