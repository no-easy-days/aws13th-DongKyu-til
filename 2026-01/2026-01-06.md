### 로그인

**POST** `/users/login`

이메일과 비밀번호로 인증을 수행하고, API 호출에 필요한 Access Token을 발급받습니다.

**Request Headers**

| 헤더 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| Content-Type | String | O | application/json |

**Request Body**

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| email | String | O | 회원 이메일 |
| password | String | O | 회원 패스워드 |

**Request Example → Reqeust Body 가 있는 경우 작성 필**

```json
{
  "email": "test@example.com",
  "password": "test12345678!"
}
```

**Response (200 Ok)** 

```json
{
  "status": "success",
  "data": {
    "user_id": "user_0001",
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9",
    "refresh_token": "dGVzdC1yZWZyZXNoLXRva2Vu",
    "expires_in": 3600
  }
}
```

### 회원가입

회원가입

**POST**`/users/signup`  

새로운 회원을 등록합니다. 이메일, 비밀번호, 닉네임은 필수이며 프로필 이미지는 선택 사항입니다.

**Request Headers**

| 헤더 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| Content-Type | String | O | application/json |

**Request Body**

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| email | String | O | 회원 이메일 |
| password | String | O | 회원 비밀번호 |
| nickname | String | O | 회원 닉네임 |
| image | String | X | 회원 프로필 이미지의 URL 주소 |

**Request Example → Reqeust Body 가 있는 경우 작성 필요**

```json
{
  "email": "test@example.com",
  "password": "test12345678!",
  "nickname": "test123",
  "image": "https://github.com/test/images/my-profile.jpg"
}
```

**Response (201 Created)**

```json
{
  "status": "success",
  "data": {
    "user_id": "user_0001",
    "nickname": "test123",
    "image": "https://github.com/test/images/my-profile.jpg",
    "created_at": "2026-01-06T12:00:00Z"
  }
}
```
