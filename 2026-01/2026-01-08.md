## 간단한 웹 서비스 만들기

### 1. 아키텍처 (Architecture)

우리가 만든 서비스는 **Client(화면) <-> Server(파이썬) <-> Database(창고)** 세 가지 요소가 서로 대화하며 돌아갑니다.

- **Client (HTML/JS):** 사용자의 입력을 받고, 결과를 보여줍니다.
- **Server (FastAPI):** 중간 관리자입니다. 요청을 받아 DB에 명령을 내립니다.
- **Database (SQLite):** 데이터를 영구적으로 저장하는 창고입니다.

---

### 2. 백엔드 핵심 로직 (Python/FastAPI)

서버 코드는 크게 **설계(Model), 초기화(Init), 기능(Router)** 세 부분으로 나뉩니다.

### ① 데이터의 설계 (Pydantic Model)

데이터가 어떤 모양으로 들어와야 하는지 '규격'을 정했습니다.

```python
class Memo(BaseModel):
    title: str
    content: str
```

> 배운 점: Class는 설계도일 뿐, 함수(def)를 그 안에 가두면 안 된다는 것을 배웠습니다.
> 

### ② DB 초기화 (Initialization)

서버가 켜질 때 딱 한 번, 창고와 표(Table)를 준비합니다.

```python
def init_db():
    # 
    # (IF NOT EXISTS) 추가
    cur.execute("CREATE TABLE IF NOT EXISTS memos ...")
```

### ③ 기능 구현 (CRUD)

HTTP 메서드(동사)에 따라 하는 일이 다릅니다.

- **GET (`/`):** DB에서 데이터를 꺼내(`SELECT`), 리스트로 포장해서 HTML에게 던져줍니다.
- **POST (`/memos`):** HTML이 준 데이터를 검사하고 DB에 집어넣습니다(`INSERT`).
- **DELETE (`/memos/{id}`):** 특정 번호(id)를 가진 데이터를 찾아 삭제합니다(`DELETE`).

---

### 3. 프론트엔드 핵심 로직 (HTML/JS) (from gemini)

화면은 단순히 보여주는 것을 넘어, 비동기 통신(Fetch)을 통해 서버와 대화합니다.

### ① 데이터 보여주기 (Jinja2 Template)

파이썬이 보내준 데이터를 HTML 구멍에 채워 넣습니다.

```html
{% for memo in memos %}
    <td>{{ memo.title }}</td>
{% endfor %}
```

### ② 데이터 보내기 (JavaScript Fetch)

새로고침 없이 서버로 데이터를 쏩니다.

```jsx
fetch('/memos', {
    method: 'POST', // 
    body: JSON.stringify({ title: "...", content: "..." })
})
.then(() => location.reload());
```

### 4. 핵심 트러블 슈팅 (내가 겪고 해결한 것)

이 부분이 공부 노트의 하이라이트입니다.

- 함수를 클래스 안에 잘못 넣으면 인식이 안 되거나 에러가 남.
