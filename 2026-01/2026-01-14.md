## 📝 배운 내용 (Today I Learned)

### 1. FastAPI 기초 (Basics)

FastAPI는 빠르고, 배우기 쉬우며, 자동으로 문서를 만들어주는 Python 웹 프레임워크

- **기본 구조:**
    
    ```python
    from fastapi import FastAPI
    app = FastAPI()  # 인스턴스 생성
    
    @app.get("/")    # 경로 및 메서드 정의 (데코레이터)
    async def root(): # 비동기 함수 정의
        return {"message": "Hello World"} # JSON 응답 반환
    ```
    
- **실행:** `fastapi dev main.py` (개발 모드, 자동 재시작)
- **문서 확인:** `/docs` (Swagger UI), `/redoc` (ReDoc)

### 2. 파라미터 3대장 (Path, Query, Body)

API가 클라이언트로부터 데이터를 받는 3가지 주요 방식입니다.

### ① Path Parameters (경로 파라미터)

리소스의 **위치(식별자)**를 지정할 때 사용합니다.

- **형태:** URL 경로 안에 `{변수명}` 포함
- **특징:**
    - 타입 힌트(`int` 등)를 주면 자동 변환 및 검증 수행.
    - **순서 중요:** 고정 경로(`users/me`)를 동적 경로(`users/{user_id}`)보다 **먼저** 선언해야 함.
    - `Enum`을 사용해 입력 가능한 값을 제한할 수 있음.
    - 경로 자체를 값으로 받을 땐 `:path` 사용 (예: `{file_path:path}`).

### ② Query Parameters (쿼리 파라미터)

데이터를 **정렬, 필터링, 검색**할 때 등 부가적인 옵션에 사용합니다.

- **형태:** URL 뒤에 `?key=value&key2=value2`
- **규칙:** 경로(Path)에 없는 변수를 함수 인자로 선언하면 자동으로 Query로 인식.
- **옵션:**
    - `q: str = None` (선택적 파라미터)
    - `q: str` (기본값 없음 = 필수 파라미터)
    - `bool` 타입 자동 변환 지원 (`yes`, `on`, `1`, `true` → `True`)

### ③ Request Body (요청 본문)

클라이언트가 서버로 **보낼 데이터(내용물)**를 담습니다. (주로 POST, PUT, PATCH)

- **도구:** **Pydantic** (`BaseModel` 상속)
- **특징:**
    - 데이터 구조(Schema)를 클래스로 정의.
    - JSON 데이터를 Python 객체로 자동 변환 및 검증.
    - 에디터의 자동완성 지원(`.`) 활용 가능.
    - `model_dump()`로 딕셔너리 변환 가능.

### 3. 복합 파라미터와 유효성 검사

여러 파라미터를 섞어 쓰거나, 더 정교하게 제어하는 방법입니다.

- **파라미터 인식 우선순위:**
    1. URL 경로에 선언됨? → **Path**
    2. Pydantic 모델 타입임? → **Body**
    3. 단순 타입(int, str)임? → **Query**
- **Annotated & Body:**
    - 단순 타입을 Body로 받고 싶을 때: `Annotated[int, Body()]`
    - 단순 Body를 JSON 키로 감쌀 때: `Annotated[Item, Body(embed=True)]`
    - Body가 여러 개(Item, User)면 자동으로 키(`item`, `user`)로 감싸짐.

---

### 4. Header Parameters (헤더 파라미터)

메타 데이터(인증 토큰, 브라우저 정보 등)를 받을 때 사용합니다.

- **사용법:** `Annotated[str, Header()]`
- **자동 변환:** Python 변수명 `user_agent`는 자동으로 헤더의 `User-Agent`로 매핑됨 (`_` → ).
- **특징:**
    - `Header()`를 명시하지 않으면 Query로 인식하므로 주의.
    - 리스트(`list[str]`)로 선언하면 중복 헤더 값을 모두 받을 수 있음.
