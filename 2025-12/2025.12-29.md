### **1. 변수 (Variables & Data Types)**

데이터를 저장하는 이름표(메모리 공간)이자, 프로그램의 가장 기초적인 단위

- **선언 및 할당:** `변수명 = 값` (예: `name = "철수"`)
- **변수 이름 규칙:** 문자와 밑줄(`_`)로 시작, 숫자로 시작 불가, 예약어(if, for 등) 사용 불가

**주요 자료형 (Data Types)**

| **자료형** | **설명** | **예시** | **비고** |
| --- | --- | --- | --- |
| **int** | 정수 | `age = 25` | 소수점 없음 |
| **float** | 실수 | `pi = 3.14` | 소수점 있음 |
| **str** | 문자열 | `name = "Hi"` | 따옴표 사용, f-string(`f"{name}"`) 지원 |
| **bool** | 논리형 | `is_ok = True` | True / False |
| **None** | 값 없음 | `x = None` | 빈 상자가 아닌 '상자 자체가 없음' |

**컬렉션 (여러 값을 담는 자료형)**

- **리스트 (List) `[]`**: 순서 있음, 수정 가능 (CRUD 가능)
    - 예: `cart = ["우유", "빵"]`

- **튜플 (Tuple) `()`**: 순서 있음, **수정 불가**. (주로 DB에서 사용)
    - 예: `loc = (37.5, 127.0)`

- **딕셔너리 (Dict) `{}`**: 키(Key)-값(Value) 쌍 키로 값을 찾음
    - 예: `user = {"이름": "철수", "나이": 20}`

- **세트 (Set) `{}`**: 순서 없음, **중복 불가**
    - 예: `lotto = {1, 2, 3}`

### **2. 함수 (Functions)**

반복되는 코드를 묶어 재사용성을 높이고, 유지보수를 쉽게 만들기 위해 사용

- **기본 구조:**
    
    ```python
    def 함수이름(매개변수):
        # 실행할 코드
        return 반환값
    ```
    
- **매개변수(Parameter) vs 인자(Argument):**
    - 매개변수: 함수 정의 시 사용하는 변수 (`def add(a, b):`)
    - 인자: 함수 호출 시 넘겨주는 실제 값 (`add(1, 2)`)
- **주요 기능:**
    - **기본값(Default):** `def greet(name="친구"):` (인자 생략 시 기본값 사용)
    - **키워드 인자:** 순서 상관없이 이름으로 지정 (`func(city="Seoul", age=20)`)
    - **Scope(범위):** 함수 안(Local) 변수는 밖(Global)에 영향을 주지 않음. (`global` 키워드 사용 지양)
- **내장 함수:** 파이썬이 기본 제공하는 함수 (`print()`, `len()`, `type()`, `sum()` 등)

### **3. 제어문 / 반복문 (Control Flow & Loops)**

프로그램의 흐름을 조건에 따라 나누거나 반복

**조건문 (if)**

- 상황에 따라 다른 코드를 실행
- 구조: `if` (만약) → `elif` (그게 아니고 만약) → `else` (나머지)
    
    ```python
    if age >= 20:
        print("성인")
    else:
        print("청소년")
    ```
    

**반복문 (for, while)**

- **for문:** 횟수가 정해져 있거나 리스트 등을 순회할 때 사용
    
    ```python
    for i in range(5):  # 0부터 4까지 5번 반복
        print(i)
    ```
    
    - *Tip:* `enumerate()`(순번 포함), `zip()`(여러 리스트 동시 순회) 활용 가능.
- **while문:** 조건이 참인 동안 계속 반복 (횟수를 모를 때)
    
    ```python
    while count < 5:
        count += 1
    ```
    

**제어 키워드**

- `break`: 반복문 즉시 탈출 (멈춰!)
- `continue`: 이번 턴만 건너뛰고 다음 반복 진행 (패스!)

### **4. 에러 처리 (Exception Handling)**

프로그램 실행 중 발생하는 예상치 못한 상황(예외)에 대비하여 프로그램이 비정상 종료되는 것을 막습니다.

- **기본 구조 (try-except):**
    
    ```python
    try:
        # 에러가 발생할 수 있는 코드
        result = 10 / 0
    except ZeroDivisionError:
        # 에러 발생 시 실행될 코드
        print("0으로 나눌 수 없습니다.")
    except Exception as e:
        # 그 외 모든 에러 처리
        print(f"알 수 없는 에러: {e}")
    else:
        # 에러가 없을 때 실행
    finally:
        # 에러 여부와 상관없이 무조건 실행 (정리 작업)
    ```
    
- **자주 발생하는 에러:**
    - `ValueError`(값 문제)
    - `TypeError`(타입 문제)
    - `ZeroDivisionError`(0 나누기)
    - `IndexError`(범위 초과)
- **raise:** 필요에 따라 개발자가 강제로 에러를 발생시킬 때 사용

### **5. 클래스 (Classes)**

관련된 데이터(속성)와 기능(함수/메서드)을 하나로 묶어 관리하는 설계도

- **개념:**
    - **클래스(Class):** 붕어빵 틀 (설계도)
    - **인스턴스(Instance):** 붕어빵 (실제 생성된 객체)
- **기본 구조:**
    
    ```python
    class Student:
        # 생성자 (__init__): 객체 생성 시 자동 실행, 속성 초기화
        def __init__(self, name, score):
            self.name = name   # 속성 (데이터)
            self.score = score
    
        # 메서드: 클래스 내부의 함수 (동작)
        def show_grade(self):
            print(f"{self.name}의 점수는 {self.score}점")
    
    # 인스턴스 생성 및 사용
    cheolsu = Student("철수", 90)
    cheolsu.show_grade()
    ```
    
- **self:** 인스턴스 자기 자신을 가리키는 키워드 (메서드 첫 번째 인자로 필수)
- **사용 이유:** 데이터와 기능을 구조화하여 코드의 유지보수성과 재사용성을 극대화하기 위함
