```
7. 제어문 (Control Flow) 실습
# 1. 2단부터 9단까지 출력하는 프로그램을 만드세요.
# 2. 각 단마다 1부터 9까지 곱하는 식이 나와야 합니다. (예: `2 x 1 = 2` ... `9 x 9 = 81`)


# 힌트:
# 반복문 안에 또 다른 반복문이 들어가는 구조입니다.
# 바깥쪽 루프는 '단(2~9)', 안쪽 루프는 '곱하는 수(1~9)'를 담당하게 하세요. (`range` 함수 활용)



for i in range(2, 10):
    for dan in range(1, 10):
        print(i , "X" , dan , "=",i * dan)
    # f-string 사용 안한 버전

        print(f"{i} X {dan} = {i * dan}")
    # # f-string 사용한 버전


# print(i) * print(f) 형태가 되면 for문은 순차적으로 돌아가기 때문에
# 왼쪽의 값은 그대로인채 오른쪽의 값이 순차적으로 올라가면서 계산됨.
# 그 후 오른쪽의 값이 순차적으로 진행이 끝나면 왼쪽의 값도 하나씩 증가.
```

```
10. [클래스] 쇼핑 카트 구현 실습
# [문제]
# 1. ShoppingCart 클래스를 완성하세요.
# 2. add_item 메서드: 상품정보(딕셔너리)를 self.items 리스트에 추가합니다.
# 3. get_total 메서드: self.items에 있는 모든 상품의 가격 합계를 반환합니다.

class ShoppingCart:
    def __init__(self):
        self.items = []

    def add_item(self, item, price):
        self.items.append({"item": item, "price": price})

    def get_total(self):
        # 리스트 내 모든 딕셔너리의 'price' 값을 더해서 반환
        total = 0
        for product in self.items:
            total += product['price']
        return total
```
